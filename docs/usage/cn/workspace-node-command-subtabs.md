# 工作区节点与命令窗口

节点是工作区的一级 Tab；命令窗口是节点内部的终端或 WebView。一个节点最多有 5 个命令窗口，至少保留 1 个。

## 添加与编辑窗口

1. 从顶栏右侧下拉菜单进入“工作区管理”，在左侧打开工作区和目标节点。
2. 在“命令窗口”标题右侧点击 `+` 添加终端窗口；点击地球图标添加 WebView 窗口。
3. 每个窗口填写名称。终端窗口填写启动命令；命令留空时，按节点的 profile 和启动目录启动终端。WebView 必须填写完整 URL，例如 `http://127.0.0.1:8080`。
4. 可为窗口选择图标、拖动改变顺序；删除按钮仅在节点还有其他窗口时可用。
5. 保存工作区，重新打开它以按修改后的定义创建会话。

节点 profile 和启动目录属于节点，会被该节点的终端窗口共用；WebView 不执行终端命令，而是直接加载 URL。启动本地服务是服务本身的职责，GeekTerminal 不会代为启动。

## 选择窗口布局

当节点有两个或以上窗口时，可在“多窗口展示”选择：

- **左右分隔**：多个终端同时显示；可以拖动分隔线调整各窗口比例。
- **Tab**：一次显示一个窗口；可把子 Tab 放在左上、右上或右下。

节点中有 WebView 时，应用会使用 Tab 布局；WebView 不能放进原生终端的分隔窗格。切换子 Tab 不会重启已创建的终端会话。

## 运行时行为

打开工作区时，节点按已保存配置创建。关闭一级节点 Tab 会关闭其中全部终端和 WebView；只切换节点或子 Tab 不会关闭它们。

建议按工作内容组织：例如一个节点中放 AI Agent、代码终端、启动开发服务的终端和服务的调试页面。也可以只保留一个普通终端窗口；节点并不要求使用多窗口布局。
