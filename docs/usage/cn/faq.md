# 常见问题

## 保存后为什么没有立即变化？

保存只更新工作区定义，不会重启当前已打开的会话。从顶栏左侧工作区选择器重新打开工作区，新的节点、命令窗口和布局才会创建。

## 为什么不能编辑或删除？

工作区可能已锁定。先解除锁定，再进入“工作区管理”编辑。每个节点至少要保留一个命令窗口；最多可有五个。

## 为什么 WebView 不能和终端左右分隔？

WebView 使用浏览器宿主，不能放入原生终端分隔窗格。节点含 WebView 时使用子 Tab 布局；把服务地址填入 WebView URL，并在打开工作区前自行启动服务。

## 网页窗口无法显示或空白

网页窗口依赖系统的 WebView2 Runtime。安装或更新 [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)，然后重启 GeekTerminal。也检查 URL 是否包含协议（如 `http://`）以及本地服务是否正在监听该端口。

## 关闭节点后，里面的终端为什么都没了？

一级节点 Tab 是该节点所有命令窗口的容器。关闭它会关闭所有内部窗口；只想切换窗口请使用节点内部的子 Tab。

## 配置文件在哪里？

从“工作区管理”左侧底部选择“打开配置目录”。日常配置建议通过管理页完成；手工改完文件后重新打开工作区。
