# 使用说明

[English](../eng/getting-started.md)

## 工作区管理

从顶栏右侧的下拉菜单选择“工作区管理”，会打开独立的工作区管理 Tab。

顶栏左侧的工作区选择器用于打开已保存的工作区；管理、创建和修改配置都在工作区管理 Tab 完成。

## 新建工作区

1. 在工作区管理 Tab 左侧导航底部选择“新建工作区”。
2. 选择空白工作区，或基于已有工作区创建副本。
3. 在工作区的“基本情况”中填写名称、描述、图标和颜色。
4. 选择“添加节点”，再选择新节点。
5. 为节点填写名称、配置文件、启动目录、启动命令或脚本，以及是否显示一级标签。
6. 点击底部“保存”。

保存写入工作区定义。要按新配置创建节点会话，从顶栏左侧的工作区选择器打开该工作区；编辑不会重启已打开的工作区。

## 节点与命令窗口

节点对应一级 Tab，通常代表一个子项目。一个节点可放多个命令窗口，例如 AI Agent、源代码终端、开发服务和调试页面，仍归在同一节点下。

在节点页面的“命令窗口”区域添加终端窗口或 WebView 窗口。终端窗口使用节点的配置文件和启动目录；WebView 窗口填写完整 URL。详见[工作区节点命令窗口](workspace-node-command-subtabs.md)。
