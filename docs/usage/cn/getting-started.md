# 使用说明

Windows Terminal Geek Portable Edition 用工作区组织一组相关的终端和网页工具。一个工作区可以包含多个节点；每个节点在一级标签栏中占一个标签，并可包含一个或多个命令窗口。

[English](../eng/getting-started.md)

## 启动

直接执行下载的可执行文件即可。

## 语言

程序会自动使用系统语言。修改系统界面语言后，请重新启动应用。

## 创建和编辑工作区

1. 点击左上角的工作区名称，打开工作区管理页。
2. 新建工作区，或选择已有工作区。
3. 新建节点，选择终端 profile，并按需填写启动目录和节点名称。
4. 进入编辑模式后修改配置；完成后保存并重新打开工作区，使新的会话配置生效。
5. 需要防止误改时锁定工作区。锁定后先解锁，才能继续编辑。

节点的终端窗口会继承节点所选 profile 和启动目录。关闭一个节点的一级标签，会关闭该节点中的全部命令窗口。

## 配置命令窗口

每个节点可以配置 1 至 5 个命令窗口：

- 使用 `+` 添加终端命令窗口。填写名称和启动命令；命令留空时，仅启动节点 profile。
- 使用地球图标添加网页窗口，填写名称和完整 URL，例如 `http://127.0.0.1:8080`。
- 点击命令窗口左侧图标可修改图标；拖动条目可调整顺序。
- 两个或以上窗口可选择多窗口展示方式。网页窗口使用 Tab 展示方式，不支持分隔展示。
- 子 Tab 可显示在左上、右上或右下。切换子 Tab 不会重启已创建的终端会话。

完整的命令子 Tab、WebView 和 codev 配置示例见[工作区节点命令子 Tab 使用说明](workspace-node-command-subtabs.md)。

## 网页窗口

网页窗口使用系统安装的默认 WebView Runtime。程序不会下载、安装、打包或指定其版本和路径。

如果网页无法显示或显示异常，请从 [WebView Runtime 官方页面](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 安装或更新运行时，然后重新启动应用。网页窗口只负责显示网页；本地服务（例如 codev）需要先自行启动。

## 常见检查

- 工作区无法编辑：确认工作区处于未锁定状态，并已进入编辑模式。
- 新配置没有出现：保存配置后重新打开该工作区，以创建新的会话。
- 网页窗口空白或无法加载：先在普通浏览器中验证 URL 和本地服务，再检查 WebView Runtime 是否为最新版本。
- 需要查看变更：阅读对应语言的[发行说明](release-notes.md)。
