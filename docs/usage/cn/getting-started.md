# 使用说明

[English](../eng/getting-started.md)

## 先理解工作区、节点和窗口

工作区是一套可重复打开的开发会话配置，不是强制的项目结构。它可以是一整个大型项目，也可以是一套开发、预发布或生产环境。

节点通常对应工作区中的一个子项目。一个节点可以组织一组协作窗口：多个 AI Agent 终端、代码终端、开发服务、调试页或 Web 工具。它是常用的落地方式，不限制你必须这样组织。

命令窗口属于节点，而不是一级 Tab。这样一个节点仍只占一个一级 Tab，相关会话在节点内部切换或并排显示。

## 打开与创建工作区

- 顶栏左侧的工作区选择器：打开已保存的工作区。
- 顶栏右侧下拉菜单的“工作区管理”：创建、编辑、复制、删除和保存工作区。

创建流程：

1. 在工作区管理左侧底部选择“新建工作区”，选择空白工作区或以已有工作区为模板。
2. 在工作区的“基本情况”设置名称、说明、图标和颜色。
3. 在“节点默认值”设置新节点默认使用的 profile、启动目录、输入面板、Tab 标题和是否显示一级 Tab。
4. 点击工作区导航项中的 `+`，新增空白节点，或从现有节点复制模板。
5. 打开节点，设置名称、profile、启动目录、图标，以及节点内的命令窗口。
6. 点击底部“保存”，再从顶栏左侧选择器打开该工作区。

保存的是定义；已经打开的工作区不会被编辑操作重启。要按新定义创建会话，需要重新打开工作区。

## 编辑与日常使用

工作区“基本情况”页面可拖动调整可见节点的一级 Tab 顺序。节点页面可配置 profile 和启动目录；同一节点的命令窗口可单独命名、设置图标、调整顺序和删除。

需要防止误操作时锁定工作区。锁定后不能继续改动工作区结构；先解除锁定再编辑。关闭一个节点的一级 Tab 会关闭它所含的全部命令窗口。

详细的终端、WebView、Tab 和并排布局配置见[工作区节点命令窗口](workspace-node-command-subtabs.md)。Docker/code-server 示例及如何配入 WebView 见[Docker 版 VS Code Web](code-server-docker.md)。

## 配置文件

工作区管理左侧底部的“打开配置目录”可直接进入工作区定义所在位置。常规编辑请优先使用管理页；手工修改配置后，重新打开工作区使新的会话配置生效。
