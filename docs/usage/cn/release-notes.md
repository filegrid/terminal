# 发布说明

[English](../eng/release-notes.md)

## 新增：工作区节点命令子 Tab

工作区节点现在支持最多 5 个命令窗口。多个窗口仍归属于同一个一级节点 Tab，并在节点内容区中以命令子 Tab（或右侧竖排图标）切换，避免多个相关命令占用顶层标签栏。

- 支持为每个命令窗口设置名称、图标和启动命令，并通过拖放调整顺序。
- 支持“Tab”展示方式及左上、右上、右下三种子 Tab 位置。
- 终端命令窗口独立启动，切换子 Tab 不会重启已创建的会话。
- 新增 WebView 命令窗口，可将本机或内网 Web 工具嵌入节点，例如 code-server/codev 的 `http://127.0.0.1:8080`。
- 新增 WebView 时自动选择 Tab 展示方式；WebView 不支持左右分隔展示。
- 工作区命令配置格式升级为 v3，同时保持对旧版单命令和 v2 配置的读取兼容性。

完整操作与 codev 集成示例见[工作区节点命令子 Tab 使用说明](workspace-node-command-subtabs.md)。
