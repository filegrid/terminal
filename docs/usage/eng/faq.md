# FAQ

## A web window does not load

Web windows use the default system WebView Runtime. Start the local service yourself before opening its URL.

If a page does not render correctly, install or update the [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/), then restart GeekTerminal.

## Workspace changes do not take effect

Save the workspace and reopen it. Node and window changes take effect when their sessions are created again.
