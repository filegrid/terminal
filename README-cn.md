# Windows 终端（极客便携版）

![工作区概览](res/images/all.png)

## 项目信息

- **版本**：0.0.1
- **作者**：tommy（tommy.yxd@gmail.com）

## 项目目标

这是一个面向多项目、多模块开发场景的 Windows Terminal 便携版，重点解决
终端现场恢复、工作区组织和命令输入效率问题。

## 主要功能

### 工作区

- 通过左上角的工作区名称进入统一管理入口。
- 一个工作区同一时间只在一个终端窗口中打开。
- 可锁定工作区，避免误操作；解锁后可继续编辑和管理。
- 终端节点可根据 profile、SSH 配置、启动目录和启动命令恢复现场。

![工作区菜单](res/images/menu.png)

![工作区管理](res/images/manage.png)

### 底部输入面板

- 每个终端节点独立控制显示状态，默认隐藏。
- 输入框从一行开始并根据内容自动增高。
- 使用 `Ctrl+Enter` 向当前终端发送内容并补回预期的回车行为。
- 未发送内容会被缓存，工作区重启后仍可继续编辑。

### 便携发布与 SSH

- 产品以单文件便携程序发布和运行。
- 当前提供中文与英文界面版本。
- 支持从 SSH 配置加载连接信息，并对已有连接去重。
- 能识别经 `ssh -t` 进入 Windows 目标时的启动目录恢复时机。

## 目录约定

- `src/`：工作区核心逻辑、Terminal glue 层，以及 `src/generated/` 下由构建生成的头文件。
- `res/`：工作区资源。
- `tools/`：构建与资源生成工具。
- `microsoft/`：Windows Terminal 源码和依赖。
- `bin/`：最终便携版产物。
